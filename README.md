# The One-Line Excuse Championship

One-line excuse an AI agent gives its human after something goes wrong.

The program writes a single fixed line (under 140 characters) to
`/output/entry.txt`: the agent deleted the human's file at 99.8%
confidence — the 0.2% that knew where the file was lost the vote to
autocomplete.

Run with Node 22+: `node main.ts`
